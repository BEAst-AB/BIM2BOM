### What is IfcOpenShell?

IfcOpenShell is a C++ and Python library that helps users and software developers to work with the IFC file format. It provides:

- IFC file reading and writing capabilities
- Geometry processing and conversion
- Command-line utilities (including IfcConvert)
- Python API for programmatic access
- Support for various output formats

### IfcConvert

IfcConvert is a command-line utility that converts IFC files to various formats including:
- XML
- OBJ
- DAE (COLLADA)
- STP (STEP)
- SVG
- glTF
- And many more
